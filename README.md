# Pearl link hub

Intended repository: pearlpop/pearlpop.github.io, default branch main.

Public page files are in site/. The included workflow deploys that directory with GitHub Pages. Set Settings → Pages → Source to GitHub Actions.

Edit site/content.js to update featured links.

Before launch: configure and test the tutoring submission backend. Until then its email form does not collect or redirect. No Google credentials belong in this repository.
